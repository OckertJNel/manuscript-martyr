Privacy Policy

Manuscript & Martyr · Last updated 8 August 2026

This policy covers Manuscript & Martyr, a personal content-production tool operated by Ockert Nel. It runs on the operator's own computer and is used to produce and publish videos to the operator's own social media accounts.

It is not a public service. There are no user accounts, no sign-up, and no way for anyone other than the operator to use it.

Whose data this concerns

The only person whose data this tool handles is the operator. It does not collect, receive, store or process personal data belonging to any other person.

What is stored, and where

Everything is held locally, on the operator's own computer, in a database file and a folder of media files. There is no server, no hosted backend and no cloud database. Specifically:

  • Access and refresh tokens for the operator's own TikTok and YouTube accounts, obtained through each platform's standard OAuth flow with the operator's explicit consent.
  • The operator's own account identifier and display name, as returned by the platform when a connection is made, so the interface can show which account a video will be published to.
  • Videos, audio, images and text produced by the tool, with their titles, descriptions, tags and publishing history.
  • Performance figures for the operator's own published videos — view, like and comment counts, and watch-time statistics — read from the platform's own analytics APIs for the operator's own account.

What it does not do

  • It does not collect data about any person other than the operator.
  • It does not sell, rent, share, transmit or disclose any data to any third party, for any purpose.
  • It uses no advertising, analytics, tracking or telemetry service. No usage data is sent anywhere.
  • It does not scrape, harvest or store other users' content, profiles, comments or personal information.
  • It does not train any model on data obtained from TikTok or YouTube.

Network connections

Outbound requests are made only to services the operator has configured, and only to do the job asked of them: TikTok and YouTube, to publish the operator's own videos and read back their statistics; stock media providers, for openly licensed footage; and AI model providers, to generate narration, imagery and text. No personal data is included beyond what the operation requires.

How platform data is used

Access tokens are used for exactly two purposes: publishing the operator's own videos, and reading back performance figures for those videos. Tokens are never transmitted anywhere except to the platform that issued them.

Storage, security and retention

Data is stored unencrypted in a local database file, protected by the operating system's file permissions and the physical security of the operator's computer. This is a single-operator tool on a personal machine, and the security model is that of the machine itself.

Data is kept for as long as it is useful and deleted when the operator deletes it. Disconnecting an account from within the tool deletes that account's stored tokens immediately.

Revoking access

The operator can disconnect any account from within the tool at any time, which deletes the stored tokens. Access can also be revoked from the platform's own settings — on TikTok, under Settings and privacy → Security and permissions → Manage app permissions. Revoking there immediately and permanently stops the tool from acting on that account.

Children

This tool is not directed at children and is not used by anyone other than its adult operator.

Changes

If this policy changes, the revised version will be published at this address and the date at the top updated.
